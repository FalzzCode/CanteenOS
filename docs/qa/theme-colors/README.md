# Theme color QA

Verified on the dashboard, reporting module, and POS at 1280 x 742.

## Light theme

- Canvas: `#eef4f3`
- Surface: `#fffefd`
- Sidebar: `#1e3348`
- Primary: `#0d6b79`
- Accent: `#d89731`
- KPI surfaces: teal, amber, sky, slate, and violet tints
- Result: clearer hierarchy between canvas, cards, actions, alerts, charts, and navigation.

## Dark theme

- Canvas: `#1d1427`
- Sidebar: `#24182f`
- Primary: `#a963ff`
- Accent: `#ff67b9`
- Result: existing purple theme remains unchanged and keeps its stronger contrast.
